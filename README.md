# vrok Scoop bucket

Scoop manifest for [vrok](https://github.com/AliJabbar034/vrok): share files,
folders and localhost through a temporary URL, straight from your machine. No
upload, no account, and the link expires.

## Install

```powershell
scoop bucket add vrok https://github.com/AliJabbar034/scoop-bucket
scoop install vrok
```

Works on Windows x64 and ARM64.

## Update

```powershell
scoop update vrok
```

## Uninstall

```powershell
scoop uninstall vrok
scoop bucket rm vrok
```

## About this repository

The manifest `vrok.json` is generated by the vrok release workflow on every
release. Do not edit it by hand: changes are overwritten. Report problems, ask
questions or contribute in the main repository:
[AliJabbar034/vrok](https://github.com/AliJabbar034/vrok/issues).

- Website: <https://alijabbar034.github.io/vrok/>
